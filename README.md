# abubakarmugha1.github.io

Personal academic site, served by GitHub Pages as plain static files (no build step).

- `index.html` — all page content
- `assets/css/site.css` — styles (light + dark mode)
- `assets/js/theme.js` — dark-mode toggle
- `assets/fonts/` — self-hosted Lora and Figtree (SIL Open Font License)

To add a photo, save it as `assets/img/portrait.jpg` and uncomment the portrait block in `index.html`.
